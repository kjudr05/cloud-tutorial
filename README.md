## ✨ Introduction

This project is an AI-powered Resume Analyzer built using modern web technologies.  

It allows users to upload resumes, analyze them using AI, and receive feedback along with ATS scores. The system is designed to help candidates improve their resumes and match them better with job listings.

---

## ⚙️ Tech Stack

- React  
- React Router  
- Puter.js  
- Tailwind CSS  
- TypeScript  
- Vite  
- Zustand  

---

## 🔋 Features

- Easy and convenient authentication handled entirely in the browser  
- Resume upload and storage  
- AI-based resume analysis and ATS scoring  
- Custom feedback for job matching  
- Reusable and modular code structure  
- Responsive design for all devices  
- Clean and modern UI
